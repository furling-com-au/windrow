# Assumptions Register — Windrow

Every value used by the model that is **not** backed by a published source is recorded here,
with reasoning. Data files mark these values with `"provenance": "assumed"`. Simulated outputs
must never be presented as measured data.

Entry format:

```
## <assumption-id>
- **Value**:
- **Used in**:
- **Reasoning**:
- **Sensitivity**: how much the result depends on it / how to bound it
- **Upgrade path**: what data would replace it
```
